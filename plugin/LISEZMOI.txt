Contenu
-------
- Mini-synthe.vst3 : le plugin, pour Cubase, Reason (12.5 ou plus récent) et tout logiciel qui accepte le VST3.
- Mini-synthe.exe  : la même chose en logiciel autonome, sans logiciel de musique.

Installer le plugin
-------------------
1. Copie le dossier « Mini-synthe.vst3 » (tout le dossier) dans :
      C:\Program Files\Common Files\VST3\
   Windows demande une confirmation d'administrateur : accepte.
2. Cubase : il le trouve au démarrage. Sinon : menu Studio → Gestionnaire de plug-ins VST, et relance l'analyse.
   Il apparaît dans les instruments, chez le fabricant « Mickael Le Van ».
3. Reason (menus en anglais) : il vérifie les nouveaux plugins au démarrage. Sinon : Edit → Preferences → onglet Plugins.
   Il apparaît dans le navigateur, rubrique Instruments → VST.

Utiliser
--------
- Tous les réglages s'affichent en curseurs, rangés comme sur le site : 1 Oscillateur et bruit, 2 Filtre, 3 Ampli.
- Les sons de départ (Son pur, Orgue, Basse synthé, Son pincé, Cuivre, Nappe, Charleston, Vent) se choisissent
  dans la liste des presets / programmes du logiciel.
- Chaque réglage peut être automatisé sur une piste et relié à un bouton de clavier MIDI (fonctions du logiciel).
- Molette de pitch : ± 2 demi-tons. Pédale de sustain : oui.

Le logiciel autonome (Mini-synthe.exe)
--------------------------------------
Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » : clique sur « Informations
complémentaires » puis « Exécuter quand même ». Choisis ta carte son et ton clavier MIDI dans « Options ».

Version en ligne, avec les explications et l'écran : https://mlevan8395.github.io/mini-synthe/
